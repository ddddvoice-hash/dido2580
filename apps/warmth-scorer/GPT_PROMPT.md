너는 웹 프런트엔드 개발자야. 'AI 답변 따뜻함 채점기' 웹앱의 1단계를 만들어 줘.

함께 첨부한 rubric.json이 채점 기준표 원본이야. 내가 직접 만든 기준이니, 항목·점수 설명·감점 규칙의 문구를 바꾸지 말고 이 파일을 그대로 읽어서 화면을 만들어 줘.

[나에 대해]
- 17년 차 성우이자 AI 데이터 품질 검수 경력자야. AI 답변의 따뜻함을 판정하는 기준표를 만들었고, 이걸로 채점하는 도구가 필요해.
- HTML/CSS/JS와 Google Apps Script를 써 봤어. 빌드 도구 없이 파일만으로 돌아가는 코드를 원해.
- 왼손만 써서 키보드로 조작하기 쉬워야 해.

[기준표 요약 — 자세한 내용은 rubric.json]
- 평가 항목 5개(알아차림, 정확함, 존중, 절제, 다음 걸음), 각 0/1/2점, 합계 0~10점.
- 점수마다 근거 문장을 답변에서 인용해야 함 (evidence_required).
- 감점 신호 8개: 6개는 각 -2점, '위험 신호 무시'와 '사실 오류'는 합계를 0점으로 만듦. 합계는 0 아래로 내려가지 않음.
- examples에 채점 예시 1세트(답변 A/B/C)가 있음. 앱에 넣었을 때 A=0, B=4, C=10이 나와야 계산이 맞는 거야.

[1단계 범위]
1. 문항 등록: '상황'(사용자 말) 1개와 'AI 답변' 여러 개를 입력. rubric.json의 examples를 '예시 불러오기' 버튼으로 넣을 수 있게.
2. 채점 화면: 답변을 하나씩 보며 항목별 0/1/2를 고르고, 답변에서 문장을 드래그하면 그 항목의 근거로 저장. 감점 신호는 체크박스. 합계 자동 계산.
3. 저장: localStorage. 모든 채점을 JSONL 파일로 내보내기 (한 줄 = 상황, 답변, 항목별 점수, 근거, 감점, 합계, 평가자 이름, 날짜).
4. 키보드: 1~5로 항목 선택, 0/1/2로 점수, Enter로 다음 답변.

[지켜야 할 것]
- 외부 라이브러리·서버 없이 동작. 파일은 index.html, app.js, rubric.json 세 개.
- rubric.json을 fetch로 읽되, file://로 열면 fetch가 막히니 '기준표 파일 열기' 버튼으로도 불러올 수 있게.
- 버튼 높이 48px 이상, 키보드 포커스 표시, 합계는 aria-live로 읽히게.
- 한국어 존댓말, 짧은 문장.
- AI API 호출은 이번 단계에 넣지 마.

코드를 주기 전에 파일 구조와 저장 데이터 모양(JSONL 한 줄 예시)을 먼저 보여 줘. 내가 확인하면 코드를 줘.
