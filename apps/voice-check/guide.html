녹음 폴더 한꺼번에 검사하기

녹음 검사기는 브라우저가 아니라 PowerShell 창에서 씁니다. 아래 명령을 복사 버튼으로 복사해 PowerShell에 붙여 넣고 Enter 한 번이면 됩니다. 녹음 파일은 읽기만 하고 고치지 않습니다.

순서

  1. PowerShell을 엽니다(Win 키 → powershell 입력 → Enter).
  2. 폴더 전체 검사: 녹음 폴더가 (내 사용자 폴더)\voice-raw\base일 때입니다. 다른 폴더면 따옴표 안만 바꾸세요.
    cd ~/dido2580; if ($?) { node apps/voice-check/check.js "$HOME\voice-raw\base" --csv "$HOME\voice-raw\_work\검사결과.csv" }

    결과는 화면에 표로 나오고, 엑셀로 열 수 있는 검사결과.csv도 _work 폴더에 생깁니다.

  3. 기준 목소리 프로필(음높이·빠르기·쉼): 파일 하나를 봅니다.
    cd ~/dido2580; if ($?) { node apps/voice-check/profile.js "$HOME\voice-raw\base\속리산.wav" }

결과 읽는 법

표시뜻어떻게 하나
V02소리가 찢어짐(너무 큼)입력 크기를 낮춰 다시 녹음
V05끝 여백이 0.3초보다 짧거나 1초보다 김길면 자르기로 해결, 짧으면 다시 녹음
V08소리가 완전히 끊긴 구간(잡음 제거 같은 가공 흔적)가공하지 않은 원본으로 다시 저장
PEAK가장 큰 소리가 권장(-6 ~ -3 dB) 밖참고만, 다음 녹음 때 조절
ROOM
NOISE		앞 10초 조용한 구간이 없거나 시끄러움녹음 시작 뒤 10초 기다렸다 말하기
NAME파일 이름이 001_키_take01.wav 형식이 아님이름만 바꾸면 됨

빨간 표시(V로 시작)가 하나라도 있으면 그 파일은 다시 녹음하거나 손봐야 합니다. 노란 표시는 참고용입니다.

컴퓨터에 Node가 없으면 명령이 실행되지 않습니다. 자세한 규칙과 다른 도구(대본 줄 맞추기, 여백 자르기, 새 녹음 한 번에 검사)는 저장소의 apps/voice-check/README.md에 있습니다.
