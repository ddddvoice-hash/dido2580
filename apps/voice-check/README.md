# 목소리 녹음 검사기

원본 WAV가 가이드 규격에 맞는지 파일마다 검사합니다. 외부 패키지 없이 Node만 씁니다. 파일은 읽기만 하고 고치지 않습니다.

## 쓰는 법

```
node apps/voice-check/check.js <폴더나 파일...> [--json out.json] [--csv out.csv]
```

- 폴더는 하위 폴더까지 훑습니다. WAV가 아닌 파일(mp3 등)은 "WAV 아님"으로 건너뜁니다.
- 종료 코드: 반려 코드가 하나라도 있으면 1, 읽기 실패만 있으면 2, 아니면 0.
- 테스트: `node apps/voice-check/test.js` (합성 WAV를 임시 폴더에 만들고 지웁니다)
- 원본 WAV와 검사 결과 파일은 저장소에 두지 마세요.

## 코드 뜻

반려 (하나라도 있으면 다시 녹음)

| 코드 | 뜻 |
|---|---|
| V02 | 찢어짐. 최대값이 -1 dBFS 이상 |
| V05 | 여백. 마지막 말소리 끝에서 파일 끝까지가 0.3초 미만 또는 1초 초과 |
| V08 | 가공 흔적. 완전 0(샘플값 0)이 10ms(48kHz에서 480샘플) 이상 이어진 구간이 있음 |

경고 (참고용)

| 코드 | 뜻 |
|---|---|
| FORMAT | 48000Hz, 24bit, 모노가 아님 (32bit float, 스테레오 포함) |
| PEAK | 최대값이 -6 ~ -3 dBFS 밖 |
| ROOM | 첫 말소리가 10.0초보다 앞 (앞 10초는 룸톤이어야 함) |
| NOISE | 앞 10초 평균 크기가 -60 dBFS보다 큼 |
| NAME | 이름이 `001_키_take01.wav` 형식(숫자 3자리, 키에 밑줄 가능, 대소문자 무시)이 아님 |
| NOSPEECH | 말소리를 찾지 못함 (V05는 판정하지 않음) |

화면에는 길이, 형식, 최대 dBFS, 앞 말소리 시작, 뒤 여백, 완전0 구간 수가 나옵니다. 말소리가 아닌 구간의 완전 0 비율(%)과 앞 10초 평균 크기도 함께 나옵니다.

## 한계

- 말소리 구간은 `apps/reading-coach/analysis.js`의 방식(20ms 프레임 크기, 녹음마다 잡는 기준)을 그대로 씁니다. 잡음이 크거나 말소리가 전체의 10% 미만이면 틀릴 수 있습니다.
- NOISE는 앞 10초 전체의 평균입니다. 말소리가 10초 안에 들어오면 NOISE도 같이 뜹니다(ROOM과 함께 보세요).
- 스테레오는 두 채널을 평균해 분석합니다. 완전 0 판정도 평균값이 0인 샘플로 봅니다.
- 16/24/32bit PCM과 32bit float만 읽습니다. 8bit, 64bit float, 압축 WAV는 "읽기 실패"입니다.
- 한 파일에 여러 줄이 이어진 긴 녹음은 마지막 말소리 뒤 여백만 V05로 봅니다.
- 샘플 전체를 Float32Array 하나로 올리므로 메모리는 샘플 수 x 4바이트 정도 씁니다.
