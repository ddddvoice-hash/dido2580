## 촬영 방식 (`record.py`)
- 원본: 브랜치 `ccr-2099f74b-5weu5o`의 `anime/echo-canary/op-animatic.html` (커밋 d22d1e0)
- 촬영용 사본에서만: 구글 폰트를 같은 파일의 로컬 사본으로, 맨 앞에 `<meta charset="utf-8">`(원본에 없어 로컬 서버에서 한글이 깨짐), 끝에 `window.__ec` 연결 코드(원본의 `render(t)`·`schedule()`를 그대로 호출)
- 화면: `render(t)`를 1/30초마다 불러 캔버스를 그대로 저장. 소리: 같은 `schedule(0, 60)`을 OfflineAudioContext로 렌더한 원곡 가이드 트랙
- 자르는 지점은 원곡 박자(5초 시작, 0.4초 간격) 위. `render.py`가 장면 이름·박자 정렬을 확인한 뒤에만 렌더
