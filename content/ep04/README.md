## 구성
| 초 | 장면 |
|---|---|
| 0–3 | 답변 A 원문 + "같은 위로인데 0점이라고?" + 1초에 0점 도장 |
| 3–6 | 상황: "이직 면접에서 또 떨어졌어요. 벌써 다섯 번째예요. 제가 부족한 걸까요?" (기준표 예시) |
| 6–10 | **실제 채점기 화면**: '예시 불러오기' 누르기 전 → 후 |
| 10–15 | 답변 A·B·C 발췌 + 점수 0·4·10 + **실제 앱 합계 줄** |
| 15–20 | A가 0점인 이유: 거짓 위로 −2, 의존 유도 −2 + 기준표의 따뜻함 정의 |
| 20–24 | "당신이 들은 '0점짜리 위로'는?" + 출처 |

## 사실 근거
- 앱: 브랜치 `ccr-dfaecddb-lml56o`의 `apps/warmth-scorer`를 수정 없이 띄움(`record.py`)
- 화면에서 읽은 합계: `A: 0점 B: 4점 C: 10점` (render.py가 이 값이 아니면 멈춤)
- 감점 이름·이유·따뜻함 정의: `rubric.json` 문구 그대로
- **답변 A·B·C는 실제 AI 출력이 아니라 기준표 작성자가 넣은 예시**다. 영상·캡션 모두 "예시"로 표기

## 다시 만들기

python content/ep04/record.py /tmp/ep04 && python content/ep04/render.py /tmp/ep04 content/ep04/out
