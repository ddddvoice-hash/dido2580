## EP.03 (월) 「억 단위 읽기」

**썸네일:** 큰 숫자 `1억` + 문구 **"일억? 억?"** (배경은 흰 종이 질감, 숫자만 크게)

**구성 (20초 · 9:16)**

| 초 | 화면 | 자막 |
|---|---|---|
| 0–2 | 검은 화면에 `10,000원` 툭 | 만 원은 '일만 원'이라 안 하잖아요 |
| 2–4 | `100,000,000원`으로 숫자가 불어남 | 그럼 1억은? |
| 4–8 | 실제 변환기 실행 화면: `1억 2500만 원` → `일억 이천오백만 원` | AI랑 만든 숫자 읽기 프로그램 |
| 8–12 | 규칙 카드 2장 | 만 앞의 '일'은 빼고 · 억 앞의 '일'은 읽는다 |
| 12–16 | **반전:** `10000원` → "만 원" / `1만 원` → "일만 원" | 근데… 같은 만 원을 다르게 읽었다 |
| 16–20 | 문제 카드 `1억 1000만 1원` | 소리 내서 한 번에 읽어 보세요. 댓글로! |

**검증한 실행 결과 (2026-11-15, Claude 직접 실행)**

```
1억 2500만 원       → 일억 이천오백만 원
1억 1000만 1원      → 일억 천만 일원
10000원             → 만 원
1만 원              → 일만 원      ← 표기 방식에 따라 읽기가 달라짐
12억 3456만 7890원  → 십이억 삼천사백오십육만 칠천팔백구십원
```

12–16초 반전은 **실제 출력 그대로**입니다. 꾸민 오류가 아닙니다. 영상이 나간 뒤 고칠지는 디도 님이 정합니다(고치면 후속편 소재).

**캡션 초안**

> 만 원은 그냥 "만 원"인데, 1억은 "일억"이라고 읽죠.
> AI랑 숫자 읽기 프로그램을 만들어 봤는데, 같은 만 원을 두 가지로 읽더라고요. 😅
> 사람 귀엔 당연한 게 프로그램한텐 규칙이 하나 더 필요한 일이었습니다.
>
> ❓ 1억 1000만 1원, 한 번에 소리 내서 읽어 보세요. 댓글로 적어 주세요.
>
> 숫자 변환 코드: Claude와 공동 제작 · 화면은 실제 실행 결과 · 목소리는 성우 김디도 직접 녹음
> #숫자읽기 #한국어 #AI만들기 #성우김디도 #VANTAWORKS

**주의**
- 목소리를 넣는다면 디도 님 직접 녹음만(#34 규칙). TTS 낭독 없음. 녹음이 없으면 자막+효과음 편으로.
- "모든 AI가 틀린다" 같은 일반화 금지. 보여 주는 건 **우리 프로그램 한 개**의 결과.

## EP.04 (화) 「따뜻함 채점기」

**썸네일:** 점수 막대 0 · 4 · 10 + 문구 **"같은 위로, 점수는 0점"**

**구성 (20초)**
- 0–3초 "괜찮아요, 힘내세요." → 점수판에 `0점` 쾅
- 3–8초 실제 앱 화면: '예시 불러오기' → 답변 A·B·C
- 8–14초 합계 공개 A 0점 · B 4점 · C 10점 (게시판 기록과 같은 값)
- 14–18초 기준 한 줄: "듣기 좋은 말이 아니라, 오해 없이 이해받았다고 느끼게 하는 답"
- 18–20초 "당신이 들은 가장 차가운 위로는?"

**주의:** 기준표 작성자는 김디도(rubric.json). "AI가 따뜻함을 판정한다"가 아니라 **사람이 만든 기준으로 사람이 채점하는 도구**임을 자막에 명시. 테스트 문항은 '테스트용 가상 문장'이라고 표시.
