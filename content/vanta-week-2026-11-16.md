| 방식 | 조건 |
|---|---|
| ① 코드로 합성한 BGM (권장) | 시티 도미니언 효과음처럼 음원 파일 없이 코드로 생성. 저작권 부담이 없고 MP4에 바로 넣을 수 있음 |

## EP.03 (월 11/16) 「억 단위 읽기」

**형식:** 실제 앱 작동 화면 + 자막 + 코드 합성 BGM · 녹음 없음 · 20초 · 9:16

**썸네일:** 흰 바탕에 `500,000,000,000원`만 크게, 아래 작은 글씨로 **"3초 안에 읽어 보세요"**

**구성**

| 초 | 화면 | 자막 |
|---|---|---|
| 0–3 | 검은 화면에 `500,000,000,000원`, 쉼표가 하나씩 깜빡임 | 500,000,000,000원, 바로 읽을 수 있어? |
| 3–5 | 0이 4개씩 묶이며 색이 바뀜 (만·억 단위 구분) | 힌트: 0을 4개씩 끊어 보세요 |
| 5–8 | 실제 변환기 화면: `500,000,000,000원` 입력 → **오천억 원** | 정답: 오천억 원 |
| 8–12 | 실제 변환기: `1억 2500만 원` → `일억 이천오백만 원` | AI랑 만든 숫자 읽기 프로그램 |
| 12–16 | **반전:** `10000원` → "만 원" / `1만 원` → "일만 원" | 근데… 같은 만 원을 다르게 읽었다 |
| 16–20 | 문제 카드 `1억 1000만 1원` | 이건 어떻게 읽어요? 댓글로! |

**검증한 실행 결과 (2026-11-15, Claude가 `korean_numbers.py`로 직접 실행)**

```
500,000,000,000원   → 오천억 원
500000000000원      → 오천억 원
1억 2500만 원       → 일억 이천오백만 원
1억 1000만 1원      → 일억 천만 일원
10000원             → 만 원
1만 원              → 일만 원      ← 적는 방식에 따라 읽기가 달라짐
```

12–16초 반전은 **실제 출력 그대로**입니다. 꾸민 오류가 아닙니다. 고칠지는 대표가 정합니다(고치면 후속편 소재가 됩니다).

**캡션**

> 500,000,000,000원, 바로 읽으셨나요? 정답은 오천억 원입니다.
> AI랑 숫자 읽기 프로그램을 만들어 봤는데, 같은 만 원을 두 가지로 읽더라고요. 😅
> 사람 눈엔 당연한 게 프로그램한텐 규칙이 하나 더 필요했습니다.
>
> ❓ 1억 1000만 1원, 어떻게 읽으세요? 댓글로 적어 주세요.
>
> 화면은 실제 실행 결과 · 숫자 변환 코드는 Claude와 함께 만들었습니다 · 배경음은 코드로 합성
> #숫자읽기 #한국어 #AI로만들기 #VANTAWORKS

**대체 텍스트:** 검은 화면에 500,000,000,000원이 나오고, 숫자 읽기 프로그램이 '오천억 원'으로 바꿔 읽는 화면.

**주의**
- "모든 AI가 틀린다" 같은 일반화 금지. 보여 주는 건 **우리 프로그램 하나**의 결과입니다.
- 화면 녹화에 파일 경로·사용자 이름·터미널 프롬프트가 보이지 않게 합니다.
- 자막 안전영역: 가운데 x 100~900, y 300~1450 (#49).

## EP.04 (화 11/17) 「따뜻함 채점기」

**첫 화면:** "괜찮아요, 힘내세요." → 점수판에 `0점` 쾅 + 자막 **같은 위로인데 0점이라고?**

**구성 (20초)**
- 0–3초 위 훅
- 3–8초 실제 앱: '예시 불러오기' → 답변 A·B·C
- 8–14초 합계 공개 A 0점 · B 4점 · C 10점 (게시판 검수 기록과 같은 값)
- 14–18초 기준 한 줄: "듣기 좋은 말이 아니라, 오해 없이 이해받았다고 느끼게 하는 답"
- 18–20초 "당신이 들은 가장 차가운 위로는?"

**썸네일:** 점수 막대 0 · 4 · 10 + "같은 위로, 다른 점수"

**주의:** 기준표 작성자는 김디도(rubric.json)입니다. "AI가 따뜻함을 판정한다"가 아니라 **사람이 만든 기준으로 사람이 채점하는 도구**라는 걸 자막에 적습니다. 테스트 문항엔 '테스트용 가상 문장'이라고 표시합니다.
