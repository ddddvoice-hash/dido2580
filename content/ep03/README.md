## 다시 만들기

```bash
pip install playwright pillow numpy   # 브라우저는 시스템 Chromium 사용
python content/ep03/record.py /tmp/ep03      # 실제 변환기 화면 캡처
python content/ep03/render.py /tmp/ep03 content/ep03/out
```

`record.py`의 Chromium 경로(`/opt/pw-browsers/chromium`)는 클라우드 세션 기준입니다. 다른 PC에서는 `executable_path` 인자를 빼고 `playwright install chromium`을 쓰세요.
