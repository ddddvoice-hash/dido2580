# 오늘의 로또 추천 (로또 6/45)

역대 당첨번호를 분석해 **하루에 한 조합씩** 번호를 추천하고,
**지금까지 1등으로 나온 적 없는 조합만** 만들어 주는 웹 앱입니다.
설치 없이 `index.html` 하나로 동작하며, 휴대폰에서는 홈 화면에 추가해 앱처럼 쓸 수 있습니다.

## 기능

- **오늘의 번호**: 날짜(한국 시간)를 씨앗으로 가상 조합 100,000개를 뽑고, 적합도(%)가 가장 높은 6개 번호를 추천합니다. 같은 날에는 누가 열어도 같은 번호이고, 최근 7일 추천과는 겹치지 않습니다.
- **번호 생성기**: 분석 가중 / 완전 무작위 중 골라 1·5·10게임을 뽑습니다. 역대 1등 조합과 같은 조합은 나오지 않습니다.
- **역대 당첨번호 분석**: 번호별 전체 출현율, 최근 100회 출현율, 미출현 기간, 종합 가중치와 합계·홀짝·번호대 분포.
- **지난 7일 추천 기록**: 추첨이 끝난 회차는 몇 개 맞았는지 보여 줍니다.

## 적합도 계산

| 항목 | 내용 | 비중 |
|---|---|---|
| 번호 가중치 | 전체 출현율 50% + 최근 100회 출현율 35% + 미출현 기간 15% 를 0~100점으로 | 50% |
| 패턴 일치도 | 합계, 홀짝, 고저, 연속번호, 번호대 분산, AC값이 역대 당첨 조합에서 얼마나 흔했는지 | 50% |

추천일 당일 이전에 끝난 회차만 사용하므로, 토요일 추첨 결과가 들어와도 그날 추천은 바뀌지 않습니다.

> 로또는 매 회 독립 추첨이라 모든 조합의 1등 확률은 1/8,145,060 로 같습니다. 분석은 재미와 참고용입니다.

## 실행

```
# 브라우저로 바로 열기
open lotto/index.html

# 또는 로컬 서버 (홈 화면 추가·오프라인 캐시가 동작)
python -m http.server -d lotto 8000
```

GitHub Pages 에 `lotto/` 폴더를 올리면 휴대폰에서 바로 쓸 수 있습니다.
