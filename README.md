# 사주팔자로 보는 공부 성향과 두뇌 직업 적성

생년월일시를 넣으면 사주 여덟 글자를 세우고, 거기서 **공부 성향**과
**머리 쓰는 직업의 적합도**를 뽑아 주는 파이썬 패키지입니다.

운세를 점치지 않습니다. 재물운이나 결혼운도 다루지 않습니다.
오직 "어떻게 배우는 사람인가"와 "어떤 종류의 지적 노동과 맞는가" 두 가지만 봅니다.

## 쓰는 법

### 명령줄

```bash
# 기본
python -m saju 1990-05-15 10:30 --male

# 출생지와 시각 보정 기준을 지정
python -m saju 1988-11-03 04:20 --female --place 부산 --basis true

# 출생 시각을 모를 때
python -m saju 2001-02-03 --male --no-hour

# 다른 프로그램에 넘길 JSON
python -m saju 1990-05-15 10:30 --male --json > result.json
```

| 옵션 | 설명 |
|---|---|
| `--male` / `--female` | 대운 방향을 정하는 데 쓰입니다 (필수) |
| `--place` | 출생지. 경도 보정에 씁니다. 기본 서울 |
| `--basis` | `standard`(시계 그대로) / `local`(경도 보정, 기본) / `true`(균시차까지) |
| `--no-hour` | 출생 시각을 모를 때. 시주를 비웁니다 |
| `--yajasi` | 야자시설 적용 (23시 이후에도 일주를 넘기지 않음) |
| `--careers` | 표시할 직업 개수 (기본 6) |
| `--json` | JSON 출력 |

### 라이브러리

```python
from datetime import datetime
from saju import read

reading = read(datetime(1990, 5, 15, 10, 30), is_male=True, place="서울")

print(reading.report)                       # 텍스트 리포트 전체
print(reading.analysis.axes.scores)         # {'흡수력': 65.2, '표현력': 21.8, ...}

for fit in reading.analysis.top_careers(3):
    print(fit.career.name, fit.score, fit.reason())
```

단계별로 쓸 수도 있습니다.

```python
from saju import build_saju, analyze, text_report, TimeBasis

chart = build_saju(
    datetime(1988, 11, 3, 4, 20),
    is_male=False,
    place="부산",
    basis=TimeBasis.TRUE_SOLAR,
)
print(chart.grid())                 # 원국 표
print(chart.day_master)             # 일간

result = analyze(chart)
print(result.elements.strength_label)     # 신강/신약
print(result.gods.group_percent)          # 십성 그룹 분포
print(result.best_study_years(3))         # 학업에 유리한 대운
print(text_report(result))
```

## 계산이 어떻게 이루어지나

### 1단계 — 출생 시각 보정 (`timeutil.py`)

시계가 가리킨 시각과 태양이 실제로 하늘에 있던 위치는 다릅니다. 세 가지를 조정합니다.

- **표준시 변경**: 한국은 UTC+8:30 과 UTC+9 를 오갔습니다 (1908~1911, 1954~1961년이 +8:30).
- **서머타임**: 1948~1951, 1955~1960, 1987~1988년 여름에 시행됐습니다.
  이 시기에 태어났다면 시주가 통째로 한 칸 밀릴 수 있습니다.
- **경도차와 균시차**: 서울은 표준자오선(동경 135°)보다 서쪽이라 태양이 약 32분
  늦게 남중합니다. 여기에 지구 공전궤도가 타원이라 생기는 균시차(-14~+16분)가 더해집니다.

앞의 두 가지는 `zoneinfo` 의 Asia/Seoul 이력을 그대로 씁니다.

### 2단계 — 절기 계산 (`solar_terms.py`)

연주는 1월 1일이 아니라 **입춘**에 바뀌고, 월주는 매달 1일이 아니라 **절(節)** 에
바뀝니다. 달력으로는 알 수 없으므로 태양의 겉보기 황경을 직접 계산해 절입 시각을 찾습니다.

### 3단계 — 사주 산출 (`pillars.py`)

| 기둥 | 경계 | 기준 시각 |
|---|---|---|
| 연주 | 입춘 | 절대 시각 (절기는 전 세계 동시 사건) |
| 월주 | 12절 | 절대 시각 |
| 일주 | 23시 (정자시설) | 보정된 지역 태양시 |
| 시주 | 두 시간 단위 | 보정된 지역 태양시 |

대운은 양년생 남자·음년생 여자가 순행, 나머지가 역행하며,
절입까지의 날수를 3으로 나눠 시작 나이를 정합니다.

### 4단계 — 십성과 오행 세력 (`tenstars.py`)

일간을 '나'로 놓고 나머지 글자와의 관계를 십성으로 환산합니다. 세력을 잴 때는

- 월지를 가장 무겁게(1.8), 일지를 그다음(1.4)으로 봅니다.
- 지지는 표면 글자가 아니라 **지장간 비율대로** 나눠 담습니다.
- 마지막에 월령에 따른 왕상휴수 계수를 곱합니다.

가중치는 `Weights` 로 바꿔 끼울 수 있습니다.

### 5단계 — 능력 축으로 환산 (`analysis.py`)

십성·오행·신살을 **열한 개 축**으로 모읍니다.

> 흡수력 · 표현력 · 논리력 · 창의력 · 정밀성 · 몰입력 · 지구력 · 경쟁력 · 실행력 · 소통력 · 직관력

중간에 축을 한 번 거치는 이유는, 직업마다 "정인이 몇 점" 식으로 규칙을 적으면
수십 개로 불어나고 서로 모순되기 때문입니다. 축으로 묶으면 직업 정의가 짧아지고,
**왜 그 직업이 추천됐는지 설명이 됩니다.**

점수는 0~100이고 **50이 평균**입니다. 이 '평균'은 가정이 아니라 실측값입니다 —
1940~2038년 사이 무작위 생년월일시 3,000개로 사주를 만들어 각 축의 중앙값이
50이 되도록 맞췄습니다(`tools/calibrate.py`). 그렇게 하지 않으면 축마다 분포가
달라(창의력은 43 근처, 몰입력은 54 근처) 특정 축을 요구하는 직업이 구조적으로
불리해집니다.

### 6단계 — 직업 적합도

20개 두뇌 직업이 각각 어떤 축을 얼마나 요구하는지 정의돼 있고, 적합도는 그
가중평균입니다. 직업 목록과 가중치는 `analysis.CAREERS` 에 있으니 고쳐 쓸 수 있습니다.

## 정확도와 검증

계산 결과는 독립 구현체와 대조해 확인했습니다.

| 항목 | 대조 대상 | 결과 |
|---|---|---|
| 일주 (60갑자) | `sxtwl` 만세력, 1900~2050년 무작위 3,000일 | **3,000건 전부 일치** |
| 연주·월주 | `sxtwl`, 1920~2029년 무작위 4,000건 | **불일치 0건**<br>(절입 당일 85건은 이쪽이 시각까지 따져 맞음) |
| 절기 시각 | `ephem`, 1930~2060년 324개 절 | ephem 백엔드 **평균 0.0분**<br>내장 급수 평균 4.6분 / 최대 12.6분 |
| 입춘 시각 | 한국천문연구원 발표값 | 2024년·1984년 모두 **2분 이내** |
| 균시차 | 알려진 범위 (-14.2 ~ +16.4분) | -14.1 ~ +16.5분 |

`sxtwl` 과 달랐던 85건은 모두 **절입 당일** 사례였습니다. `sxtwl` 은 월주를
날짜 단위로 매기지만 이 패키지는 절입 시각까지 비교하므로, 절입 **전** 에 태어난
사람에게 이전 달 간지를 줍니다. 85건 전부 이 이유로 설명됩니다.

절기 경계나 자시 경계에 태어난 경우에는 리포트에 **경고가 함께 출력**됩니다.

```
■ 계산상 유의사항
  ! 입추 절입(08-07 09:09) 11분 전에 태어났습니다. 월주가 갈리는 경계이니
    만세력으로 확인하세요.
```

## 알아 두어야 할 것

**이것은 통계적으로 검증된 적성검사가 아닙니다.** 전통 명리 이론을 코드로 옮긴
결과이며, 같은 사주라도 해석하는 유파에 따라 결론이 달라집니다. 이 패키지가
택한 입장은 다음과 같고, 전부 다른 선택이 가능합니다.

- 일주는 23시에 넘깁니다 (정자시설). `--yajasi` 로 바꿀 수 있습니다.
- 시각은 지방평균태양시를 기본으로 씁니다. `--basis` 로 바꿀 수 있습니다.
- 지지는 지장간 비율로 나눠 세력을 잽니다. 표면 글자만 세는 유파도 있습니다.
- 신살은 학업 관련 9종만 봅니다.

진로를 좁히는 근거가 아니라, 자신을 다른 각도에서 살펴보는 재료로 쓰시기 바랍니다.
점수가 낮은 직업이라도 "못 한다"가 아니라 "같은 결과를 내는 데 더 많은 의식적
노력이 든다" 쪽으로 읽는 편이 맞습니다.

## 이 저장소의 다른 앱

사주 패키지 말고도 목소리·낭독 작업용 앱이 `apps/` 아래에 있습니다. 모두 녹음 파일을 저장소에 올리지 않고, 외부 AI API를 부르지 않습니다.

| 앱 | 하는 일 | 여는 법 (Windows PowerShell) |
|---|---|---|
| `apps/voice-studio` 디도 녹음 부스 | 대본 96줄 녹음, WAV 바로 검사, 시선·동선·호흡·동작 메모 | `start apps/voice-studio/index.html` |
| `apps/voice-persona` 보이스 페르소나 실험실 | 안내 원문 사실 보존, 같은 원고 A/B 녹음의 말소리·쉼 비교 (Streamlit) | `cd apps/voice-persona; if ($?) { python -m streamlit run app.py }` |
| `apps/voice-check` 녹음 검사기 | 반려 코드(V02·V05·V08), 기준 프로필, 일괄 검사, AI 음성 비교 (Node) | `node apps/voice-check/check.js <폴더>` |
| `apps/reading-coach` 낭독 따라 읽기 코치 | 시범 낭독과 따라 읽기의 속도·쉼 비교 | `start apps/reading-coach/index.html` |
| `apps/warmth-scorer` 따뜻함 채점기 | AI 답변을 기준표(`rubric.json`)로 채점, JSONL 내보내기 | `start apps/warmth-scorer/index.html` |

푸시할 때마다 GitHub Actions(`.github/workflows/tests.yml`)가 사주 패키지, 보이스 페르소나, 녹음 검사기·녹음 부스 테스트를 모두 돌립니다.
