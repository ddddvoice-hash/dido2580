# 대표 사례: AI는 숫자를 맞게 읽어도, 사람처럼 끊고 올리지 못한다 · 성우 김디도

2026-10-06 · **v2** · 클라우드 팀장 · 대표 확인 + GPT 아스트라 G15(숫자 문장 30개)·R24(정답 읽기 검토) 반영 · Q13·R25(심각도) 비교 대기

## 대표가 들은 것 (이 사례의 출발점)

성우 김디도는 국내 대형 플랫폼 AI 음성 비서의 학습용 녹음을 직접 읽었고, 만들어진 AI 목소리를 들었다. 사람과 가장 다르게 들린 곳은 숫자였고, 그 차이는 **틀린 읽기가 아니라 억양과 끊어 읽기**였다. 대표의 판단으로는 **지금 나와 있는 AI들 모두**에서 같은 차이가 들린다(대표 확인, 2026-10-06).

- 이것은 성우 김디도의 청취 관찰이에요. 이 사례에서는 대표가 직접 녹음한 **여러 AI 목소리**로 그 관찰을 보여 주고, 결과는 "모든 AI"가 아니라 **녹음한 서비스 범위**로 적어요.
- 숫자 값을 맞게 읽는지(정확성)는 기본 확인이고, 이 사례의 중심은 **사람처럼 들리는지(자연스러움)**예요. 국제 음성 품질 평가 관례(ITU-T P.85)도 알아들을 수 있음과 자연스러움을 따로 봐요.

## 두 축으로 판정해요

| 축 | 무엇 | 코드 | 판정 |
|---|---|---|---|
| **정확성** (기본 확인) | 숫자 값·단위·대상이 그대로 전달되는가 | NUM-V 값 바뀜(누락·추가·순서·영 빠짐) · NUM-R 수사 선택(고유어/한자어) · NUM-S 특수 읽기(유월·시월) · NUM-U 기호·단위 | 값·단위·대상이 바뀌면 **반려**. 값은 그대로인데 어색한 수사 선택("삼 시간")은 자연스러움 축으로 넘김(R24-2·8·19) |
| **자연스러움** (이 사례의 중심) | 사람이 말하듯 끊고, 올리고 내리는가 | **NUM-C 끊어 읽기**: 숫자 덩어리, 숫자와 단위·뒷말 사이 경계 · **NUM-P 억양**: 경계 밖의 강조·높낮이(대조 강조, 물음·대답 말끝, 나열 리듬) | **0·1·2점 + 구간(초) + 수정 요청.** 끊는 자리 때문에 다른 숫자로 들리면(원고를 모르는 사람의 받아쓰기로 확인) 정확성 축 **반려**로 올림 |

자연스러움 축은 "경미한 오류"가 아니에요. 이 키트가 보려는 **사람다움의 핵심**이라 따로 점수를 매겨요. 심각도 가중치(MQM)는 정확성 축에만 써요. 최종 경계는 GPT 독립 안(Q13)과 비교한 뒤 확정해요.

**검수 카드** (문제 하나마다): 문항·음성 ID · 시작~끝(초) · 들린 것 · 기대한 것 · 축과 코드 · 점수/심각도 · 수정 요청(한 줄) · 재확인 조건 · 확신도

## 녹음할 문장 — 시연 12개

R24 제안(D01~D12)을 뼈대로, 대표가 들은 **끊어 읽기·억양이 드러나는 문장**으로 일부를 바꿨어요. 전화번호는 실제 번호와 겹칠 위험이 있어 빼고(R24-10), 같은 성격의 **예약 번호**로 대신해요.

| # | 문장 | 기본 읽기(숫자 부분) | 주로 듣는 것 |
|---|---|---|---|
| D01 | 오전 9시 30분에 출발해요. | 아홉 시 삼십 분 | 시각 덩어리 |
| D02 | 오전 4시 25분에 시작해 2시간 10분 동안 진행해요. | 네 시 이십오 분, 두 시간 십 분 | 시각과 기간이 이어질 때 끊기 |
| D03 | 가상 전시는 10월 6일에 시작해 6개월 동안 열려요. | 시월 육 일, 육 개월 | 시월/육 개월 구별, 끊기 |
| D04 | 총 1,234,500원이 결제됐어요. | 백이십삼만 사천오백 원 | 긴 금액의 자릿값 덩어리 |
| D05 | 예약 번호는 4719-2386이에요. | 사칠일구, 이삼팔육(한 자리씩) | 번호 덩어리와 쉼 |
| D06 | 3시가 아니라 4시에 만나요. | 세 시, 네 시 | **대조 강조**(네 시에 힘) |
| D07 | 몇 개 남았어요? 2개요. | 두 개요 | 물음·대답의 말끝 억양 |
| D08 | 1번, 4번, 7번 문항을 다시 보세요. | 일 번, 사 번, 칠 번 | 나열 리듬 |
| D09 | 체온이 38.5도예요. | 삼십팔 점 오 도 | 소수점 앞뒤 끊기 |
| D10 | 연습용 측정값은 0.05예요. | 영 점 영 오 | 영 보존, 끊기 |

| D12 | 배터리가 15% 남았고 5km 남았어요. | 십오 퍼센트, 오 킬로미터 | 기호 단위와 이어 말하기 |

## 검증용 새 문장 8개 (시연 뒤, 처음 보는 문장에 기준 적용)

결과를 듣기 전에 정답·허용 읽기를 고정하고, 결과가 좋은 문장만 남기지 않고 8개 모두 보고해요(R24-V09).

| # | 문장 | 기본 읽기 |
|---|---|---|
| V01 | 연습용 가격은 23,040원이에요. | 이만 삼천사십 원 |
| V02 | 연습용 비율은 0.08%예요. | 영 점 영 팔 퍼센트 |
| V03 | 도형의 2/5만 색칠해요. | 오분의 이 |
| V04 | 4번째 상자에 카드 21장을 넣어요. | 네 번째, 스물한 장 |
| V05 | 가상 규칙의 제4조 3항을 읽어요. | 제사조 삼 항 |
| V06 | 연습용 상자의 질량은 1.06kg이에요. | 일 점 영 육 킬로그램 |
| V07 | 2시 5분, 2시 15분, 2시 50분 중에 고르세요. | 두 시 오 분, 두 시 십오 분, 두 시 오십 분 |
| V08 | 오늘 기온은 영하 3도에서 영상 12도까지 올라가요. | 영하 삼 도, 영상 십이 도 |

허용 읽기(예: 예약 번호의 "일/하나", 금액의 "일만")는 녹음 전에 정하고, 정하지 못한 것은 "확인 필요"로 두어 반려 집계에서 빼요(R24-13).

## 녹음 방법

| | 대표가 할 일 |
|---|---|
| 사람 녹음 (목표 낭독) | 시연 12개 + 검증 8개를 평소처럼. 근거표 v3.2의 녹음 조건(여백 각 1초 이상 등) |
| AI 소리 | **대표가 직접**, 쓸 수 있는 AI 음성 서비스 **2~3곳**에서 같은 20문장을 만들어요. 마이크로 다시 받지 말고 내려받은 파일이나 컴퓨터 안 소리를 그대로 저장해요. 서비스 이름은 공개 자료에 쓰지 않고 A·B·C로 적어요. 이용 약관상 시연에 써도 되는지 확인해요 |
| 보관 | 녹음·AI 소리는 저장소에 올리지 않아요 |

사람 녹음은 **목표 낭독**이라고 표시해요. AI를 실제로 다시 만들어 나아진 소리가 없으면 "개선 전·후"라고 하지 않아요(R24-23).
