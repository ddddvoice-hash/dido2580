# GPT 협의 기록

대표 지시(2026-10-05): GPT와 무엇을 협의했고 어떻게 대응했는지 매번 보고한다. GPT는 **아스트라 모델**로 돌린다(AGENTS.md "실행 모델").
GPT는 대표 PC의 팀장 터미널(codex)에서만 돌 수 있다. 평소엔 읽기 전용 리뷰, 아스트라로 확인되면 `docs/gpt/`에 직접 초안도 쓴다(G 업무)와 질문(Q)에 답한다. 클라우드 Claude는 GPT를 직접 부르지 못하고, 게시판으로 요청하고 결과를 받는다.

새 기록이 위로 온다. "모델"은 실행 기록에 찍힌 이름을 그대로 적는다. 기록이 없으면 "기록 없음"이라고 적는다.
