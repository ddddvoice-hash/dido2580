## 1. 평가가 말해 주는 지형

공개 문서의 평가를 배역별로 모으면 뚜렷한 경계가 보여요. `[공개]`

| 호평 | 배역 | 평가에 나온 말 |
|---|---|---|
| ★ | 트릭스터(살인마, 게임) | 광기 어린 웃음과 과한 호흡이 뒤틀린 인물을 잘 담음, 해외 이용자 반응이 특히 좋음 |
| ★ | 라피트(원피스) | 능글한 성격을 잘 살림, 맡은 배역 중 평가가 가장 좋음, 이전 판보다 낫다는 평도 |
| ★ | 어른 맹구(극장판) | 얼떨떨하고 둔감한 연기를 매우 잘 살림 |
| ★ | 젤러시트·박지만(특촬) | 개그 캐릭터에 강점 |
| ★ | 잔크로우 | 열혈 캐릭터, 소리 지르는 연기 |
| ★ | 만쥬맛 쿠키(게임) | 여유로운 미성 |
| ★ | 멜트(첫 특촬 주역) | 진지한 미형이라 걱정했으나 의외로 잘 맞음 |
| ◐ | 레온(첫 애니 주역) | 1기 혹평(장난기만 살고 쿨시크함이 없음) → 시리즈마다 개선 |
| ★ | 듄(최종 보스) | 외침과 웃음소리 호평. 공개 문서의 "캐스팅 평이 나빴다"는 서술에는 **대표가 동의하지 않음** — 약점 근거로 쓰지 않아요 |
| ✕ | 중년 간부·노련한 인물들 | 무게감·카리스마 부족, 나이에 비해 너무 젊은 톤 |

### 경계선 `[추측]`
```
            밝음·능글·광기
                  ▲
   ★ 라피트       │       ★ 트릭스터
   ★ 어른 맹구    │       ★ 잔크로우
   ★ 개그 괴인    │       (외침·웃음·숨)
 젊음 ───────────┼─────────── 
   ◐ 레온(쿨시크) │       ✕ 중년 간부
   ★ 멜트(진지)   │       ★ 듄(외침·웃음)
                  ▼
            차분함·무게·저음
```
- **가장 강한 자리:** 젊고, 밝거나 능글맞고, 감정이 바깥으로 터지는 인물. 그 끝에 광기.
- **약했던 자리:** 나이 든 무게감, 저음의 카리스마(중년 간부 배역 평가).
- **넘어선 자리:** 진지한 미형 주역(멜트)은 노력으로 넘었어요. 경계는 고정이 아니에요.

## 2. 이 목소리만의 무기 세 가지 `[추측]`

1. **대사 밖의 소리.** 웃음, 외침, 거친 숨. 혹평받은 배역에서도 이것만은 호평받았어요. 대본에 글자로 안 적히는 소리를 만드는 능력이에요. 같은 대사를 읽는 성우는 많지만, 웃음 한 번으로 인물을 보여 주는 성우는 적어요.
2. **미성과 광기의 낙차.** 바탕이 부드러운 미남 톤이라, 같은 목소리가 무너질 때 듣는 사람이 더 놀라요. 다정하게 시작해서 미쳐 가는 인물에 최적이에요.
3. **능글맞음.** 라피트, 어른 맹구, 개그 괴인. 진심인지 장난인지 모르게 하는 줄타기예요. 이건 정확한 타이밍 감각이 있어야 나와요.

## 3. 두 개의 얼굴: 캐릭터와 신뢰 `[공개][추측]`

| 캐릭터의 얼굴 | 신뢰의 얼굴 |
|---|---|
| 트릭스터, 라피트, 개그 괴인, 열혈 | 시사 다큐 내레이션, 유아 채널 내레이션 다수, 생활 속 전화 안내, 광고 30여 편 |
| 터지고, 웃고, 무너지는 목소리 | 맑고, 친근하고, 믿고 듣게 되는 목소리 |

같은 사람이 **아이들 채널에서 친절하게 안내하고, 게임에서 웃으며 사람을 쫓는 살인마**를 해요. 이 폭 자체가 아이덴티티예요. 바탕의 미성이 두 얼굴을 잇는 다리고요.

## 4. 성우로서의 습성 (공개 문서에 적힌 것) `[공개]`

- 혹평을 피하지 않고 **스스로 인정하는 글**을 쓰고 다음 시리즈에서 나아진 모습을 보임.
- 바쁜 와중에도 **맡은 작품을 미리 정주행**.
- 첫 특촬 주역을 앞두고 **배역과 같은 머리색으로 탈색**.
- 아끼는 배역을 **직접 게임으로 플레이하는 영상**을 올림.
- 공개 문서가 붙인 말: **"엄청난 노력파"**.
- 무대: 연극(체호프 〈갈매기〉의 메드베첸코), 뮤지컬(〈흥부와 놀부〉의 놀부), 거리 공연. 몸으로 하는 연기에 익숙함.

→ **배역 안으로 들어가는 성우**예요. 머리색, 정주행, 직접 플레이까지, 목소리를 넘어 인물 전체를 입어요. `[추측]`

## 5. 성장 서사 `[공개][추측]`

> 첫 주역에서 "가볍다"는 혹평 → 본인이 인정 → 시리즈마다 개선 → 진지한 미형 주역에서 "의외로 맞는다" → 해외에서 먼저 알아본 광기의 웃음.

**재능만이 아니라 고쳐 온 기록이 있는 성우**예요. 이 서사는 캐스팅하는 사람에게 "디렉션을 주면 바뀌는 사람"이라는 신뢰가 돼요.

| 광기·웃음이 터지는 최종 보스(듄) | 공포 게임·스릴러 오디오 드라마의 주역 | |
