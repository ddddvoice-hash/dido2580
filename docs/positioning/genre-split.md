# 성우 김디도 장르화 · Claude와 GPT(아스트라) 업무 분담

2026-10-13 · 클라우드 팀장(Claude) · 대표 요청: "추론하고 지피티랑 어떻게 분담할지 추론해서 나눠봐"
함께 보는 문서: `docs/positioning/genre-claude.md`(클라우드 추론 초안)

## 1. 나누는 기준: 각자 잘하는 것과 못 하는 것

| | Claude (클라우드 팀장) | GPT 아스트라 (대표 PC) |
|---|---|---|
| **이번 협업에서 보여 준 강점** | 여러 결과를 하나로 합치기, 코드·도구·페이지 만들기, 시험으로 확인하기, 저장소에 바로 반영 | 출처를 찾아 대조하기(공식 문서·링크), 남이 만든 것의 빈틈·과장 찾기(R28~R38), 문항을 정책 질문으로 묶기(G19) |
| **제약** | 대표 PC를 직접 못 씀, 실제 녹음·청취 못 함 | 대표 PC에서만 돎, 큰 파일을 읽으면 메모리 부족(두 번 멈춤), `docs/gpt/`에만 씀 |
| **실행 방식** | 이 세션에서 바로 | 대표가 GPT 대화창을 열어야 시작 (`tools/gpt-chat.cmd`) |

## 2. 분담 원칙

1. **바깥 세계를 조사하는 일은 GPT**: 역사 사례, 공개 반응, 권리·법, 플랫폼 관행처럼 출처가 필요한 일.
2. **만들고 합치는 일은 Claude**: 규칙 문서, 도구, 페이지, 계획표, 두 결과의 통합.
3. **판단이 중요한 일은 둘이 따로 먼저**: 장르 이름처럼 결론이 갈릴 수 있는 일은 각자 독립으로 쓰고, 그다음 서로 비판.
4. **한 쪽이 쓰면 다른 쪽이 비판**: Claude가 만든 건 GPT가, GPT가 만든 건 Claude가 봐요.
5. **GPT 업무는 작게**: 한 번에 하나, 읽을 파일은 짧게, 웹 검색은 필요한 만큼.
6. **최종 결정은 대표**: 장르 이름, 공개 범위, 본인 목소리 사용.

## 3. 일감 지도 (장르 조건 ①~④에 맞춰)

|---|---|---|---|---|
| 역사 사례 조사(국내외, 출처) | 전체 | **GPT** (Q17) | Claude | 출처 확인은 GPT 강점 |
| 김디도 공개 반응 조사(해외 반응·평가 흐름, 출처) | ① 알아보는 특징 | **GPT** (Q18) | Claude | 웹 조사 |
| 장르 씨앗 가설과 이름 | ③ 이름표 | **둘 다 독립** (Claude 초안 완료 · GPT Q17) | 서로 (R39) | 결론이 갈릴 수 있음 |
| 숨연기 규칙 5개(누구나 따라 하는 쉬운 규칙) | ② 따라 할 규칙 | **Claude** (C1) | GPT (R40) | 기존 기준표에서 줄여 만듦 |
| AI vs 김디도 비교 클립 제작 도구(대본·공개 TTS·자막) | ① | **Claude** (C2) | GPT (R41) | 코드·도구 제작 |
