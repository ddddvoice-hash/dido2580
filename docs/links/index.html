성우 김디도 링크 모음

AI 목소리가 얼마나 사람에 가깝게 들리는지, 사람이 듣고 같은 기준표로 판단해 어디가 다른지 찾는 평가 키트예요. 목소리가 중심이고, 답변 내용이 사람이 건네는 말 같은지는 보조로 봐요. 필요한 링크 하나만 골라 여시면 돼요.

참여해 주시는 분

따뜻함 채점 베타베타 v0.1 열기 → 키트의 '말의 내용' 부분. AI 답변 28개를 따뜻함 기준표로 채점하고 헷갈린 점을 남겨요. 1시간 30분~2시간(추측), 나눠서 해도 돼요. 평가자 코드는 성우 김디도에게 받아요.

둘러보시는 분

성우 김디도 평가 키트 열기 → 키트 소개. 다정해 보이는 답이 왜 0점인지 예시 채점부터, 된 것과 남은 것까지. AI 답변의 따뜻함 평가 기준표 열기 → 기준 다섯 개(알아차림·정확함·존중·절제·다음 걸음)와 감점 신호 여덟 개, v1.0. 성우 김디도 포트폴리오 열기 → 17년 경력 성우 김디도의 작업 모음.
