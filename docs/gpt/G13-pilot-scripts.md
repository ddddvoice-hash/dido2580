[Q10 예비 녹음 설계](Q10-answer.md)의 Q10-5~Q10-13을 따르는 원고예요. G13-01~06은 여백 규칙을 고르는 데 쓰고, G13-07~08은 규칙을 선택한 뒤 처음 적용하는 재확인용으로 남겨 둬요. 모두 일상 사물의 모양·배치·정리를 다루며, 상담·위기·감정 상황은 넣지 않았어요.

**읽는 방법과 시간 계산이에요.**

- 표의 원고만 읽어요. `/`는 내부 쉼 자리이고 소리 내어 읽지 않아요. 질문형마다 이 자리에서 약 0.5초 쉬는 것을 출발점으로 제안해요. 적절한 쉼 길이라는 판단은 **추측**이에요. 첫머리 `음,` 뒤에는 별도의 고정 쉼을 요구하지 않아요.
- `…`는 마지막 모음의 힘이 자연스럽게 줄어드는 끝맺음 표시예요. 음절을 빼거나 일부러 속삭이지 않아요. 첫머리의 `음`과 `ㅎ`으로 시작하는 말도 과장하지 않고 평소처럼 읽어요. 실제로 약한 경계가 생길지는 **추측**이며 녹음으로 확인해야 해요.
- 음절 수는 Python으로 원고를 NFC 정규화한 뒤 `가`~`힣`에 해당하는 글자 수를 셌어요. `음`은 1음절로 포함하고 공백·문장부호·`/`·`…`는 제외했어요. 실제 발음의 축약 여부를 측정한 값은 아니에요.
- 예상 길이는 초당 4~5음절을 가정한 **추측**이에요. 평서문은 `음절 수 ÷ 5`~`음절 수 ÷ 4`, 질문형은 여기에 내부 쉼 0.5초를 더했어요. 표의 길이는 첫 말소리부터 마지막 말소리까지이며 앞뒤 룸톤을 포함하지 않아요. 추가 호흡·쉼·말끝 늘임은 계산에 넣지 않았어요.
- 쉼이 적은 평서문도 필요한 호흡은 자연스럽게 해요. 범위에 맞추려고 서두르거나 숨을 참지 않아요. 실제 길이가 목표를 벗어나면 그 값을 그대로 기록해요.

**Q10 설계에 연결하는 방법이에요.**

1. 규칙 선택용 6개를 각각 ‘평소 안내 낭독’과 ‘그 상황의 사람에게 말하듯’의 두 방식으로 두 번씩 읽어 **24개 원본**을 확보해요. 두 번째 방식도 사물의 배치나 정리를 상대에게 설명하듯 읽어요. 순서를 미리 섞고 모든 테이크를 보존해요.
2. 장소·장비·거리·각도·입력 크기를 고정하고 자동 음량·잡음 처리를 끈 WAV로 녹음해요. 원본 앞뒤에는 각각 2초 이상 자연 룸톤을 확보해요. 사람이 표시한 첫·끝 말소리를 기준으로 각각 0.5·1.0·1.5초를 남긴 사본을 만들어 **72회 분석**해요. 무음 삽입·음량 보정은 하지 않고 호흡·잡음의 위치를 기록해요.
3. 두 사람이 자동 결과를 보지 않고 청취·파형으로 말소리와 내부 쉼 경계를 표시해요. 경계 차이가 40ms를 넘으면 다시 확인하고, 합의하지 못하면 ‘기준 시각 불확실’로 남겨요. 검출 성공과 경계 정확도는 따로 확인해요.
4. Q10의 임시 기준은 조건별 실패 0개, 시작·끝 절대오차가 각각 중앙값 40ms 이하·최댓값 100ms 이하예요. 명확한 300ms 이상 내부 쉼은 누락·추가 없이 길이 오차 100ms 이하인지 확인하고, 200~320ms 경계 사례는 따로 기록해요. 이 허용 오차의 충분성은 Q10에서 제안한 **추측**이며 검증된 표준은 아니에요.
5. 먼저 1초를 평가하고 미달이면 1.5초를 평가해요. 0.5초는 비교 조건으로 남겨요. 선택 후 G13-07~08을 같은 두 방식·두 테이크로 녹음한 **새 원본 8개**에 선택 규칙을 적용하고 같은 기준으로 재확인해요. 재확인 결과를 보고 원고별로 규칙을 바꾸지 않아요. 실패·불확실 사례를 빼고 통과시키지 않으며, 기준에 미달하면 확정을 보류해요.
