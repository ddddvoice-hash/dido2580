공통으로 **허용되는 읽기나 단순 취향 차이는 오류가 아니에요.** G15에도 추측으로 표시된 허용안이 있으므로, 그 문서를 그대로 확정 정답표로 사용하면 안 돼요. 반려 전에 문항별 정답·허용안·사용 맥락을 먼저 고정해야 해요.

**④·⑤는 다음 절차로 확인하는 안을 제안해요. 인원과 반려 수치는 국제 규정이 아닌, 검증 전의 잠정 운영값이에요.**

1. **일반 청취자와 전문 검수자의 역할을 나눠요.**  
   문항과 원고를 모르는 한국어 능숙 청취자 **유효 응답 12명/음원**을 확보하고, 별도로 전문 검수자 **2명**이 오류 위치와 원인을 확인해요. 원고를 아는 제작자의 판단은 일반 청취자 결과에 섞지 않아요. 12명은 초기 내부 검수 규모 제안이며, 통계적 충분성이 입증된 수는 아니에요.

2. **정답을 보여 주기 전에 처음 들은 결과를 받아요.**  
   음원 출처를 가리고 순서를 무작위로 제시해요. 전체 문장을 한 번 들려준 뒤, 들은 숫자·기호·단위와 뜻을 적게 해요. “모르겠어요”도 허용해요. 다시 듣기는 첫 응답을 저장한 다음 허용하고, 응답이 바뀌었는지 따로 기록해요. 같은 문장의 다른 버전을 먼저 들려주면 정답을 학습하므로, 첫 청취 비교는 평가자를 나누거나 문항을 교차 배정해요.

3. **숫자 문자열과 의미를 함께 채점해요.**  
   숫자만 맞아도 단위나 연결 대상을 틀리면 전달 실패예요. 반대로 한글·아라비아 숫자 표기 차이와 일반적인 띄어쓰기 차이는 오답으로 처리하지 않아요. 끊어 읽기의 경계 자체가 중요하면 경계를 표시하게 하고, 억양이 문장 의도를 바꿀 가능성이 있으면 이해한 뜻도 적게 해요. **받아쓰기만으로 자연스러움 통과를 판정하지 않아요.**

4. **이해 노력과 운율을 따로 평가해요.**  
   이해 노력은 P.800의 다섯 단계 취지를 따라 물어요. 별도로 끊어 읽기와 억양 각각에 자체 척도를 사용해요: **5 매우 자연스러워요 / 4 대체로 자연스러워요 / 3 어색함이 있지만 쉽게 따라갈 수 있어요 / 2 어색함이 뚜렷하고 반복돼요 / 1 매우 부자연스러워요.** 이 운율 척도는 자체안이며, P.800의 표준 MOS와 동일하다고 표시하지 않아요.

5. **아래 규칙을 결과를 보기 전에 확정해요.**

| 판정 경로 | 잠정 반려 조건 | 심각도·처리 |
|---|---|---|
| 의미 전달 실패 | **12명 중 3명 이상**이 같은 핵심 숫자 구간의 값·단위·연결 대상·의도를 잘못 이해하고, 전문 검수자 2명이 해당 운율 결함을 확인해요. | **중대·반려**예요. 답이 모두 같은 오답일 필요는 없지만, 실패 구간은 연결돼야 해요. |
| 이해 노력 과다 | **12명 중 8명 이상**이 ‘상당한 노력이 필요해요’ 또는 그보다 나쁜 단계로 평가하고, 검수자가 같은 구간의 결함을 확인해요. | 받아쓰기가 맞더라도 **중대·반려**예요. |
| 자연스러움 기준 미달 | 자연스러움이 필수 납품 조건인 작업에서, **12명 중 8명 이상**이 끊어 읽기 또는 억양에 **2점 이하**를 주고, 검수자들이 구체적 결함과 위치를 확인해요. | 의미가 정확해도 **중대·반려**예요. 단순히 사람 음원보다 덜 선호된다는 이유만으로 적용하지 않아요. |
| 제한적인 어색함 | 위 조건에 이르지 않고, 의미 전달·이해 노력에 문제가 없으며 국소적인 어색함만 확인돼요. | **경미·수정 권고**예요. |
| 판정 불일치 | 오답 원인이 원고의 모호함·기억 부담·재생 상태일 수 있거나, 전문 검수자가 합의하지 못해요. | **판정 보류 후 재검증**해요. 표 수가 적다는 이유만으로 자동 통과시키지 않아요. |

**치명 판정은 이 다수결 규칙과 별도로 다뤄야 해요.** 심각한 피해 위험이나 전체 기능 실패가 구체적으로 확인되면, 다수의 오답을 기다리지 않고 반려해요. 다만 “기계 같음”이나 “자연스러움 2점”만으로 치명으로 올리지는 않아요. 이는 MQM의 영향 중심 구분을 음성 검수에 적용한 제안이에요.

인과관계가 불확실하면 동일한 내용에서 끊어 읽기·억양을 수정한 음원을 만들어 **새로운 청취자**에게 확인하는 것이 좋아요. 내용·음량·음질 등 다른 차이를 최대한 통제해야 해요. 사람이 읽은 음원에서 성적이 좋아졌다는 사실만으로 원인이 억양이었다고 단정할 수는 없어요.

또한 검수자의 소수 의견이라는 이유로 응답을 제외하면 안 돼요. 환경·주의 확인 등 사전에 정한 제외 기준을 적용한 뒤, 유효 인원·오답 원자료·점수 분포와 불확실성을 함께 남겨요. 전체 평균이 높아도 특정 숫자 문항의 반려를 상쇄하지 않도록 해요.

대표가 들으신 **억양·끊어 읽기 차이는 독립 평가 항목으로 유지할 근거가 충분해요.** 다만 이번 반려 판정의 단위는 우선 **해당 문장·해당 음원**으로 두는 것이 적절해요. 한 음원의 실패로 엔진 전체를 반려하거나, 모든 AI의 한계로 일반화하는 것은 별도 검증 전에는 추측이에요. 같은 구간에서 NUM-C와 NUM-P가 겹치면 두 현상은 기록하되, 동일한 실패를 중복 가산하지 않는 안을 권해요.
