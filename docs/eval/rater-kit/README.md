# 평가자 안내문·동의서 템플릿 · 성우 김디도

두 번째 평가자(그리고 그 뒤의 평가자)에게 드릴 **안내문, 참여 동의서, 운영자 확인표**의 틀이에요.

- 만든 방법: GPT 아스트라(`gpt-6-astra`)가 Q9(평가자 고르기)와 G12(안내문·동의서 초안, `docs/gpt/G12-rater-consent.md`)를 쓰고, 클라우드 팀장(Claude)이 사실을 다시 확인하고 다듬었어요. 분량(조정용 10문항·28답, 최종 20문항·56답, 겹침 0)은 묶음 파일에서 다시 셌고, 위기 문항 접기 화면은 채점기 검사 38건으로 확인했어요.
- 법률상 필수 항목·별도 심의 필요 여부·보관 의무는 **확인하지 않았어요.** 실제로 쓰기 전에 확인이 필요해요.

## 쓰는 법

1. `values.json`을 `values.R-K7.json`처럼 평가자 코드를 붙인 이름으로 복사해요(이 이름은 저장소에 올라가지 않아요).
2. 복사한 파일의 빈칸을 채워요. 평가자 코드는 이름·이니셜과 상관없는 코드로 정해요.
3. 저장소 폴더에서 아래 한 줄을 PowerShell에 붙여 넣어요.

```powershell
cd ~/dido2580; if ($?) { python docs/eval/rater-kit/fill.py docs/eval/rater-kit/values.R-K7.json }
```

4. 빈칸이 남아 있으면 무엇이 비었는지 알려 주고 멈춰요. 다 채워지면 `docs/eval/rater-kit/out/R-K7/`에 세 파일이 생겨요(이 폴더도 저장소에 올라가지 않아요).

| 파일 | 누구에게 | 내용 |
|---|---|---|
| `1-rater-guide.md` | 평가자 | 목적, 세 번의 일정과 분량, 순서, 위기 문항, 보상, 기록·공개, 철회 |
| `2-consent-form.md` | 평가자 | 체크로 고르는 동의서(참여·위기 문항·공개 범위) |
| `3-operator-checklist.md` | 성우 김디도 | 회차마다 확인할 것(답 열쇠는 보내지 않기 등) |

## GPT 초안에서 바꾼 것 (클라우드 판단)

| 바꾼 것 | 이유 |
|---|---|
| 빈칸을 문서마다 흩어 두지 않고 `values.json` 한 곳에서 채움 | 한 손으로 여러 문서를 오가지 않게. 빠진 칸은 스크립트가 잡아냄 |
| "연구자" → "운영" | 정식 연구 심의를 거친 것처럼 읽히지 않게 |
| 4~6시간을 한 번에 → 세 번(조정용·이야기·최종)으로 나눠 안내 | 평가자 부담. 시간은 여전히 추측이라고 표시 |
| 도움 요청 칸을 비워 두지 않고 109·112·119를 미리 넣음 | 이미 절차 문서(`calibration.md`)에 있는 번호 |
| "화면 기능을 전제하지 않음" → "채점기가 본문을 접어 두고 먼저 물음" | 매니저 A10이 구현했고 검사 38건 통과를 확인 |
| 운영자 확인표를 새로 만듦 | 답 열쇠·최종 계획을 평가자에게 보내지 않는 일 등, G12에 흩어진 운영 규칙을 한 장으로 |
| 근거표(230줄 중 절반)는 템플릿에서 빼고 GPT 원본에 남김 | 평가자에게 줄 문서는 짧게 |
