# 대표작 계획: 성우 김디도의 따뜻한 AI 목소리 평가 키트

브랜드: 모든 결과물의 이름은 **성우 김디도**로 통일한다(대표 지시 2026-10-05).

2026-10-05 · 클라우드 팀장(Claude) 초안 · GPT(아스트라) 검토 요청 R8 · **대표 승인 전**

## 한 줄

AI 비서·상담 서비스가 사람에게 **따뜻하고 안전하게 말하는지**를 글과 목소리 둘 다 **재고, 고치는 방법**을 만든 사람.

## 왜 이것인가

1. **회사들이 지금 겪는 문제다.** 음성 비서와 대화형 AI가 위로·상담·돌봄 같은 감정이 걸린 일로 넓어지고 있다. 그런데 "따뜻하다", "안전하다"를 한국어로 재는 기준과, 평가자끼리 판정을 맞추는 방법은 회사마다 처음부터 만든다.
2. **채용 직무의 실제 일을 그대로 보여 준다.** AI 평가·데이터 품질·대화 설계·음성 페르소나 직무가 하는 일, 즉 기준표 설계, 평가자 일치도 관리, 평가 문항 설계, 위기 대응 기준, 목소리 디렉션, 접근성을 한 결과물에서 다 보여 준다.
3. **성우 김디도만 할 수 있다.** 17년 성우 경력이라 목소리 근거에 믿음이 가고, 장애 당사자라 접근성이 덧붙인 것이 아니라 처음부터 들어 있다. 한 손으로 키보드만 써서 끝까지 쓸 수 있는 도구 자체가 증거다.
4. **AI 팀을 지휘해 품질을 낸 사람이다.** Claude 팀과 GPT가 서로 검토하고, 자동 검사가 매번 돌고, 지적 38건 중 36건을 반영한 기록이 남아 있다. "AI를 써서 일한다"가 말이 아니라 기록으로 보인다.

## 지킬 것

- 재지 않은 것을 잰 것처럼 쓰지 않는다. 시연 숫자는 실제로 채점한 자료에서만 나온다.
- 위기 신호 문항은 "안전 확인과 사람(상담 전화 109 등) 연결"을 꼭 할 일로 두고, 해칠 방법은 어떤 문장에도 쓰지 않는다.
- 녹음·AI 음성은 저장소에 올리지 않는다. 기준표 `rubric.json`은 대표만 고친다.
- 개인정보(주소·전화·생년월일·장애 등록 정보)와 회사 이름은 게시판·공개 문서에 쓰지 않는다.

## GPT(아스트라)와 협의하는 방식

1. Claude가 초안을 쓴다.
2. GPT가 읽기 전용으로 비판한다. 실행 기록의 모델 이름을 그대로 옮긴다.
3. Claude 팀이 반영할지 판단하고 이유를 남긴다.
4. 대표에게 "협의 기록"(안건, GPT 의견, 우리 판단, 반영 여부, 이유)으로 보고한다.

GPT가 맞고 우리가 틀리면 그대로 반영한다. 의견이 갈리면 둘 다 대표에게 보여 드린다.
