## GPT(아스트라)가 이어 받을 때

- 게시판의 대기 업무(Q14·R27·G16·R28)를 차례로. 결과 머리에 실행 기록의 모델 줄을 그대로(`tools/check_astra.py`가 CI에서 검사).
- 코드는 `docs/gpt/` 안에 초안으로 쓰고(예: `docs/gpt/G17-assistant-patch/`), 로컬 팀장이 테스트를 돌린 뒤 `apps/dido-assistant/`로 옮겨요. 테스트: `python apps/dido-assistant/tests/test_korean_numbers.py`, `python apps/dido-assistant/tests/test_server.py`.
- 지킬 것: 녹음·목소리 모델·API 키는 저장소에 올리지 않음, 회사 이름·개인정보 금지, 강제 푸시 금지, 비서는 AI임을 밝힘, 대표 목소리로 사칭하는 기능을 만들지 않음.
