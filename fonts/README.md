# 폰트 폴더

여기에 `.ttf`를 넣으면 릴스 카드가 그 폰트를 먼저 씁니다. 오영완 계정처럼 굵고 귀여운 느낌을 내려면
아래 무료(OFL) 폰트를 추천합니다. 파일 이름을 그대로 두세요.

| 파일 이름 | 용도 | 받는 곳 |
|---|---|---|
| `BlackHanSans-Regular.ttf` | 큰 제목 | Google Fonts "Black Han Sans" |
| `Jua-Regular.ttf` | 항목 글자 | Google Fonts "Jua" |

없으면 시스템의 나눔스퀘어라운드 → 나눔고딕 → 맑은 고딕(Windows) → Apple SD 고딕(macOS) 순으로 찾습니다.
다른 폰트를 쓰려면 `REELGEN_TITLE_FONT`, `REELGEN_BODY_FONT` 환경변수에 경로를 넣으세요.
